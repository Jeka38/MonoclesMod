# Monocles mod

Форк [Monocles Chat](https://codeberg.org/monocles/monocles_chat) — XMPP-клиента для Android (сам Monocles Chat является форком [Conversations](https://conversations.im)). Использует то же пространство имён (`eu.siacs.conversations`), приложение `de.monocles.mod`.

Ниже — главные фичи, добавленные за последние два года (2025–2026).

## Групповые звонки «Видеочат» (XEP-0272)

- Полноценные аудио/видео звонки внутри конференции (Muji): плиточная видео-сетка участников, общий микрофон и камера, переключение камеры, громкоговоритель.
- Кнопка «Начать групповой звонок» в меню конференции; Telegram-подобная панель «Видеочат» вверху чата, когда звонок активен или идёт в комнате.
- Показ аватара участника вместо чёрной плитки при выключенной камере (включая распознавание «чёрных» кадров), индикатор «говорит» вокруг плитки.
- Tap-разворот любой плитки на весь экран с плавающими круглыми миниатюрами остальных участников.
- Bluetooth-гарнитура: маршрутизация аудио переживает закрытие окна звонка, звонок продолжает работать в фоне.
- Голосовой чат не создаёт отдельных диалогов и записей в «Чатах».

## Сообщения и чаты

- Отдельные постоянные окна для приватных сообщений из конференций (PM, XEP-0045) с группировкой и сворачиванием на главном экране.
- Поиск сообщений с переходом в чат и подсветкой найденного; поиск по настройкам с подсветкой результата.
- Swipe-жест слева направо для цитирования (как в Telegram), цитирование реакцией, фиксы вставки ника и цитат с вложениями.
- Подсветка сообщений, в которых упомянут ваш ник; корректный `/me`; системные сообщения конференции не засоряют предпросмотр списка чатов.
- Фиксы: стабильная сортировка диалогов, точный счётчик непрочитанных (без служебных сообщений), разделение дублей диалогов, «Отметить как прочитанное».
- Кнопки JID в сообщениях: «Добавить в контакты»/«Вступить в конференцию», меню «Copy JID / VCard» по долгому нажатию на аватар.
- Live Location: общая геолокация с отрисовкой трека маршрута в чате.

## Конференции (MUC)

- Редизайн экрана «Детали конференции»: JID комнаты всегда видим и копируется по нажатию; серверная форма настроек комнаты (XEP-0045) с русскими подписями полей.
- Управление участниками: кнопка показа/скрытия офлайна, показ банов администраторам, счётчик онлайн-участников, отдельный экран управления списками (владелец/админ/участник/бан) с вкладками и числом участников.
- Расширенное меню участника: копирование JID, смена роли/аффилиации, меню в зависимости от прав.
- Поддержка капчи при входе в комнату (включая крупный показ картинки и BOB).
- Иконки и версии клиентов участников; клиентская версия в деталях контакта и списках.
- Фикс статусов участников и приглашений; скрытие неактуальных служебных сообщений конференции из списка чатов.

## Файлы и медиа

- Скачивание файлов в публичную папку Download с сохранением оригинального имени; «Сохранить как» с корректным расширением (фикс `.null`); кнопка «Открыть файл» после скачивания.
- Отображение оригинального имени файла в чате (вложения, аудио), фикс копирования в приватное хранилище.
- Превью изображений по прямым ссылкам (включая HTTP), внутренний просмотрщик для ссылок на картинки, иконка ошибки при сбое загрузки.
- Масштабирование превью GIF (увеличение в чате, без oверлея длительности), исправленное масштабирование изображений при разной плотности экрана.
- Исправлены ручные закачки файлов при выключенной авто-загрузке.

## Смайлы и стикеры

- Полноценные кастомные смайлы: встроенный набор «Колобок», импорт пакетов ZIP (с подпапками и тщательной очисткой папки перед импортом), строгая сортировка по `icondef.xml`, мгновенная подстановка в редакторе, отправка как текст, сброс к встроенным.
- Удалена функциональность «стикеров»; смайлы по умолчанию включены и не хранятся в публичной папке.

## Клиентские иконки и определение ПО

- Иконки XMPP-клиентов на главном экране, в списках контактов, в деталях и конференциях (включая участников вне ростера).
- Встроенный набор иконок клиентов, матчинг по XEP-0115 `icondef`, иконка по умолчанию для незнакомых клиентов.
- Версия ПО клиента рядом с иконкой; определения капов синхронизируются с реальным JID.

## Сервисы и обнаружение

- Обзор служб: редактируемый адрес сервера, навигация по дереву «назад» по уровню, показ вложенных узлов (node), жирные имена.
- Диалог управления сервисом: меню действий по `disco#info`, регистрация (XEP-0077), ad-hoc команды (XEP-0050), поиск пользователей (XEP-0055) с добавлением в ростер и переходом «назад» по шагам.

## Трансфер файлов

- Передача файлов всегда через Jingle S5B при включённом Proxy65, настройки прокси-хоста/порта/транспорта.

## Настройка и мелочи

- Статус подключения аккаунта в заголовке вкладки «Чаты»; стабильная (алфавитная) сортировка списка чатов по умолчанию; опция сортировки по последнему сообщению и подсветка строки цветом аккаунта.
- По-аккаунтные приоритеты присутствия (Online/Away/XA/DND), смена статуса мгновенно меняет `<priority>`.
- Оповещения о запросах подписки, иконка непрочитанных упоминаний в панели действий.
- Убрано: проверка обновлений, отправка краш-отчётов, бэкап/восстановление, фоторедактор, кнопка медиа-браузера, запрос контактов при первом запуске, импорт иконок клиентов, упоминания поддержки из меню.
- OMEMO по умолчанию выключен, без назойливого Snackbar о шифровании.
